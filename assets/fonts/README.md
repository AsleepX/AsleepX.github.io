# Local fonts

- **Caveat**, variable weight 400–700: `caveat-latin.woff2`.
  [Upstream source](https://github.com/google/fonts/tree/main/ofl/caveat),
  license: `caveat-OFL.txt`.
- **Patrick Hand**, regular 400: `patrick-hand-latin.woff2`.
  [Upstream source](https://github.com/google/fonts/tree/main/ofl/patrickhand),
  license: `patrickhand-OFL.txt`.

The unmodified Latin WOFF2 subsets were retrieved from the Google Fonts CSS API
on 2026-10-02. They include Latin letters and general punctuation for this English
homepage. The page loads them from this directory without external font requests.
